# FAPO 007 – cashflow slev (PWA)

Statická webová aplikace bez serveru. Nasazení na GitHub Pages:
1. Vytvořte repozitář (např. `cashflow007` v účtu infosummit-sportcz) a nahrajte do kořene všechny soubory z této složky (index.html, model.js, sw.js, manifest.webmanifest, ikony, složka vendor).
2. Settings → Pages → Deploy from branch → main / (root).
3. Otevřete adresu `https://<účet>.github.io/cashflow007/`, na telefonu „Přidat na plochu“.

Použití: záložka Data (ceník + sklad 007, volitelně export prodejů pro kalibraci) → Kampaně (termín, sleva z D1, filtry) → Výsledek (graf, cashflow, export do Excelu).
Při změně aplikace zvyšte číslo verze `V` v sw.js, aby se zařízením obnovila cache.
